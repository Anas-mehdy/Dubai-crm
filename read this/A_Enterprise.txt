The more fields available, the richer the personalization. At minimum: Name + Phone + Location + Property Type.Section 2 — Classifications (التصنيفات)❓ Q5a: What detailed classifications do we need to add?✅ Recommended classification taxonomy: PRIMARY: Seller | Buyer | Renter | Investor | Developer PROPERTY TYPE: Residential | Commercial | Industrial | Mixed-Use GEOGRAPHY: Downtown / Marina / JVC / Palm / Business Bay / Other URGENCY: Immediate (0-30 days) / Mid-term (1-6 months) / Long-term (6+ months) VALUE TIER: Standard (<2M AED) / Premium (2M-10M AED) / Ultra (10M+ AED)❓ Q5b: Can leads have additional tags/labels (e.g. urgency, priority)?✅ Yes — we strongly recommend adding dynamic tags such as: 🔥 Hot Lead, ⚡ Fast Seller, 💰 High Budget, 🌍 Overseas Investor, 🔄 Re-engaged, 📞 Callback Requested, ⚠️ Do Not Contact. Tags allow agents to instantly filter and prioritize without reading full profiles.❓ Q6: Are the classifications fixed or flexible (Static vs Dynamic)?✅ We recommend a Dynamic (flexible) classification system. Start with a core set of fixed tags for consistency, but allow team admins to add new tags/categories from the Dashboard without developer involvement. Use a Tag Management Panel where admins can create, rename, color-code, and archive tags.Section 3 — Message Templates & Personalization❓ Q7a: Should we use the lead's name in the message?✅ Yes — absolutely use the lead's first name in every initial message. Personalization with name increases open/reply rates by 30-50% compared to generic messages. Example: "السلام عليكم [محمد]، وصلنا لك لأنك مهتم بعقارات في [دبي]..."❓ Q7b: What other database fields should be used for personalization?✅ Use all available fields for deep personalization: Area/Location → reference the specific neighborhood Property Type → tailor the message (villa vs apartment vs commercial) Owner/Investor Status → adjust the value proposition Budget Range (if available) → match to relevant listings Language Preference → send in Arabic or English accordingly Example: "عندنا عقار في [المارينا] بـ3 غرف نوم مناسب لـ[مستثمرين] مثلك..."Section 4 — Notifications (الإشعارات)❓ Q8: What WhatsApp number receives qualified lead notifications?✅ We recommend setting up a dedicated WhatsApp Business number for agent notifications — separate from the outbound bot number. This ensures agents receive clean, formatted alerts without noise. The notification number should ideally be linked to the team lead or a shared team inbox (e.g., using WhatsApp Business API with shared inbox tool like respond.io or Wati).❓ Q9: What exactly should be included in the notification?✅ Notification should contain a complete lead brief: 🔔 NEW QUALIFIED LEAD 👤 Name: [Full Name] 📱 Phone: [+971XXXXXXXX] (clickable) 📍 Area: [Location] 🏠 Property: [Type] 🌡️ Score: HOT 🔥 / WARM 🟡 / COLD 🔵 💬 Last Reply: "[their exact message]" 🕐 Time: [date & time] 🔗 Dashboard Link: [direct link to lead profile] Assign To: [dropdown or quick-reply buttons]Section 5 — AI Scoring System (Phase 2)❓ Q10: Which scoring metric should we use to evaluate leads?✅ We recommend a dual-layer scoring system: LAYER 1: Temperature Label (Hot / Warm / Cold) — for quick visual scanning LAYER 2: Numerical Score (0–100) — for sorting and automation rules  Hot = Score 70-100: replied, provided details, asked for follow-up Warm = Score 35-69: replied but vague, or partially engaged Cold = Score 0-34: no reply, bounced, or said "not interested"  This gives both human-readable labels AND machine-sortable precision.❓ Q11: For each category (Seller/Renter/Investor), what questions & thresholds define Hot/Warm/Cold?✅ SELLER: Questions: Do you own a property? → Which area? → Asking price? → Timeline to sell? Hot (70+): Owns property + specific price + timeline within 3 months Warm (35-69): Owns but no price/timeline confirmed yet Cold (<35): Renting, or said "just looking"  RENTER: Questions: Looking to rent or buy? → Area preference? → Budget range? → Move-in date? Hot: Budget confirmed + area + within 60 days Warm: Budget mentioned but vague timeline Cold: No budget or far future timeline  INVESTOR: Questions: Are you an investor? → Ticket size? → ROI expectations? → Cash or financed? Hot: Cash buyer + 2M+ AED + within 90 days Warm: Financed or longer timeline Cold: No clear intent or unrealistic expectations❓ Q12: How should the system handle replies — auto-reply, sequential questions, max count?✅ Recommended flow: Step 1: Send initial outbound message (personalized) Step 2: If reply received → AI analyzes intent Step 3: AI sends follow-up question 1 (e.g., "Are you looking to buy or sell?") Step 4: Based on reply → follow-up question 2 (e.g., "What's your budget range?") Step 5: Follow-up question 3 max (e.g., "When are you looking to move?") Step 6: After 3 questions → system scores lead + notifies agent + stops bot MAX = 3 qualifying questions before human handoff. Never exceed 3 in cold outreach.❓ Q13: Should the system handle Arabic, English, or both? Language detection needed?✅ Yes — implement full bilingual support (Arabic + English) with automatic language detection: - Detect language of FIRST reply from lead - Continue ALL subsequent messages in the same detected language - Maintain separate message templates for Arabic and English - Arabic messages: use Gulf dialect, right-to-left awareness - English messages: professional but warm tone - Never switch languages mid-conversation unless lead explicitly switches - Optional: add French/Russian templates for expat-heavy segments❓ Q14: What AI temperature / flexibility level should the bot use in responses?✅ Recommended: Semi-Structured AI (Temperature: 0.3–0.5) The AI should follow a strict question sequence (controlled) but allow natural-sounding variations in phrasing (flexible). It should NEVER go off-script on property details or pricing. Allow flexibility only in: - Greeting variations - Empathy phrases ("شكراً على ردك...") - Handling unexpected responses gracefully Hard constraints: Never make promises, never quote prices, never argue with the lead.Section 6 — Dashboard & Reports❓ Q15: What metrics must appear on the Dashboard?✅ Essential Dashboard metrics: 📊 Total Messages Sent (today / week / month) 📬 Reply Rate %
